# Qwen3 NPU Prefill 验证 - 快速开始指南

## 快速验证步骤

### 1. 连接到 Phoenix 服务器

```bash
ssh -p 20212 XXX@10.109.246.210
# 输入密码
```

### 2. 进入工作目录

```bash
cd /data/shrelic/mllm_v2
```

### 3. 检查代码修改

确认 `mllm/backends/qnn/op/QNNLinearOp.cpp` 已包含权重转置逻辑：

```cpp
// 在 load() 方法中应该有：
if (weight_.shape().size() == 2) {
  weight_ = weight_.transpose(0, 1);  // 转置权重
}
```

### 4. 编译项目

```bash
cd build-android-qnn-dbg  # 或你的构建目录
make -j$(nproc) mllm-qwen3-npu
```

### 5. 准备测试环境

```bash
# 创建测试目录
mkdir -p test_qwen3
cd test_qwen3

# 创建模型文件链接
ln -s /data/shrelic/mllm_v2/qwen3-1.7b-int8-rotated.mllm ./qwen3-model.mllm

# 复制配置文件和 tokenizer（需要从模型目录获取）
# cp <path>/config.json .
# cp <path>/tokenizer.json .
```

### 6. 运行 Prefill 测试

```bash
cd /data/shrelic/mllm_v2/build-android-qnn-dbg/bin
./mllm-qwen3-npu
```

### 7. 检查输出

观察以下关键信息：
- ✅ 模型加载成功
- ✅ QNN backend 初始化成功
- ✅ Prefill 执行成功
- ✅ 输出 logits shape 正确

## 常见问题

### 问题 1: 权重加载失败

**检查**：
- 模型文件路径是否正确
- 文件权限是否正确
- 权重转置逻辑是否正确实现

### 问题 2: QNN backend 初始化失败

**检查**：
- QNN SDK 是否正确安装
- 环境变量是否正确设置

### 问题 3: 编译错误

**检查**：
- CMake 配置是否正确
- 依赖库是否完整
