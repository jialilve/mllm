# 查看 Qwen3 NPU 运行日志指南

## 方法一：在 adb shell 中直接查看（推荐用于快速调试）

### 步骤：

```bash
# 1. 在主机上进入项目目录
cd ~/mllm_v2

# 2. 编译（如果需要）
python task.py tasks/build_android_qnn_debug.yaml

# 3. 进入 adb shell
adb shell

# 4. 在设备上进入测试目录
cd /data/local/tmp/zl/mllm-v2/bin_test

# 5. 运行程序，日志会直接输出到终端
LD_LIBRARY_PATH=. ./mllm-qwen3-npu

# 6. 如果输出太多，可以用 grep 过滤
LD_LIBRARY_PATH=. ./mllm-qwen3-npu 2>&1 | grep -i "Qwen3IRGraphFusionPass"
```

**优点**：实时查看，快速验证  
**缺点**：如果程序崩溃，可能看不到完整日志

## 方法三：使用 adb exec-out（在主机上直接运行并查看）

### 步骤：

```bash

cd ~/mllm_v2

# 2. 编译（如果需要）

```

**优点**：在主机上操作，可以直接保存和查看  
**缺点**：如果程序运行时间很长，终端可能超时

## 查看 Qwen3IRGraphFusionPass 日志的关键命令

### 1. 查看所有被识别的 QNN SubGraph：

```bash
# 在主机上
grep "Qwen3IRGraphFusionPass: detect" qwen3_run.log
```

### 2. 统计识别到的 Graph 数量：

```bash
# 在主机上
grep "Qwen3IRGraphFusionPass: detect" qwen3_run.log | wc -l
```

**预期结果**：28 层 × 2 个段 = 56 个 Graph

### 3. 查看特定层的识别情况：

```bash
# 查看 layer 26 的识别情况
grep "Qwen3IRGraphFusionPass: detect.*layer=26" qwen3_run.log

# 查看所有 layer 26 和 27
grep "Qwen3IRGraphFusionPass: detect.*layer=2[67]" qwen3_run.log
```

### 4. 查看识别到的 segment 分布：

```bash
# 查看所有 segment=1 的（proj 段）
grep "Qwen3IRGraphFusionPass: detect.*segment=1" qwen3_run.log

# 查看所有 segment=2 的（out+MLP 段）
grep "Qwen3IRGraphFusionPass: detect.*segment=2" qwen3_run.log
```

### 5. 查看完整的 Pass 运行信息：

```bash
# 查看 Pass 开始和结束的信息（如果有的话）
grep -i "Qwen3IRGraphFusionPass" qwen3_run.log
```

## 常见问题排查

### 问题 1：看不到任何 Qwen3IRGraphFusionPass 日志

**可能原因**：
- Pass 没有被调用（检查 `main.cpp` 中是否正确注册了 Pass）
- 日志级别设置问题（MLLM_INFO 可能被过滤）

**解决方法**：
```bash
# 查看是否有其他 Pass 的日志
grep -i "pass\|Pass" qwen3_run.log | head -20

# 查看是否有错误信息
grep -i "error\|Error\|ERROR" qwen3_run.log | head -20
```

### 问题 2：日志输出太多，难以查看

**解决方法**：
```bash
# 只查看关键信息
grep -E "Qwen3IRGraphFusionPass|ERROR|Error|error" qwen3_run.log

# 或者分页查看
grep "Qwen3IRGraphFusionPass" qwen3_run.log | less
```

### 问题 3：程序在 Pass 运行前就崩溃了

**解决方法**：
```bash
# 查看崩溃前的最后几行日志
tail -50 qwen3_run.log

# 查看是否有段错误或断言失败
grep -i "segfault\|assert\|abort" qwen3_run.log
```

```bash
# 4. 如果程序崩溃，查看错误信息
echo ""
echo "=== 错误信息 ==="
grep -i "error\|Error\|ERROR\|6033" qwen3_run.log | tail -20
```
