```Bash
adb connect 10.29.208.59:9808
cd ~/mllm_v2
python task.py tasks/build_android_qnn_debug.yaml
cd /root/mllm_v2/build-android-qnn-dbg/bin
adb shell
cd /data/local/tmp/zl/mllm-v2/bin_PR
LD_LIBRARY_PATH=. ./mllm-qwen-npu
```

## SSH命令

### 用 Clash 代理

1. 在 Windows PowerShell 重新建 SSH 连接，开远程端口转发：

```Bash
 ssh -p 6000 -R 9999:127.0.0.1:7890 root@10.29.230.87
```

1. 在服务器上导出代理环境变量

```Bash
   export http_proxy=http://127.0.0.1:9999
   export https_proxy=http://127.0.0.1:9999
   export HTTP_PROXY=$http_proxy
   export HTTPS_PROXY=$https_proxy
```

1. 验证代理可用：

```Bash
   curl -I https://google.com
```

返回 200/302 之类就说明 OK。
